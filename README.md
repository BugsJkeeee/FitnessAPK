# Tempo

Личное Android-приложение для тренировок: интервальный таймер (секундомер, таймер, For Time, AMRAP, EMOM, Табата), рандомайзер тренировок, база упражнений, журнал с рекордами и динамика веса.

Требования — [docs/TZ_Tempo_в2.docx](docs/TZ_Tempo_в2.docx).

## Как получить APK

1. Вкладка **Actions** → последний успешный запуск **Android CI** → артефакт **tempo-apk**.
2. Распакуйте архив и установите `app-release.apk` (или `app-debug.apk` — ставится отдельным приложением рядом).
3. Разрешите установку из неизвестных источников для файлового менеджера или браузера.

Все сборки подписаны общим ключом `app/debug.keystore`, поэтому новые версии ставятся поверх старых без потери данных.

## Разработка

- Kotlin, Jetpack Compose, DataStore; minSdk 26, targetSdk 35.
- Сборка и тесты — GitHub Actions (`.github/workflows/android.yml`).
- Звуки таймера синтезируются скриптом `tools/generate_sounds.py` (без сторонних записей).
