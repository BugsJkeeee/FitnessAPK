# Замечания по тестированию

## Пакет 1 (версия 0.1.9) — не исправлено

1. **Рандом: результат сбрасывается после просмотра упражнения.** Выпала тренировка → нажали на упражнение (фото) → «Назад» — тренировка пропала, вернуть нельзя. Нужно: выпавшая тренировка сохраняется при переходе к упражнению и обратно.
2. **Фильтры: «Функциональная» обрезается до «Функциональ».** Подпись должна помещаться в ячейку целиком.
3. **Фильтры: вариант «Любой» согласовать по роду с названием блока:** Тип — «Любой», Группа мышц — «Любая», Длительность — «Любая», Формат — «Любой», Сложность — «Любая».
4. **Таймер: раунды — барабаном прокрутки**, как время, вместо ввода с клавиатуры.
5. **Подготовка не корректируется, всегда 10 с.** Нужно: менять длительность подготовки прямо на экране таймера (нажатием на плитку «Подготовка» — барабан), и проверить, что значение из настроек действительно применяется.
6. **Запись комплекса в журнал (пример «Энджи»)** — предложение, ждёт подтверждения:
   - для функциональных комплексов не выводить строки «подход / повторы» по каждому упражнению — дозировка задана самим комплексом;
   - результат комплекса — время (For Time) или раунды (AMRAP), рекорд комплекса считается по нему;
   - поле «вес» показывать только для упражнений с отягощением (штанга, гантели, гиря), чтобы можно было записать, с каким весом делали; повторы не спрашивать;
   - упражнения с собственным весом в рекорды упражнений не попадают.
