# FitnessAPK — проектирование приложения

## 1. Цель

Личный дневник силовых тренировок для Android. Приложение нужно для того, чтобы в зале быстро записать подходы (вес × повторения), а дома видеть прогресс: растут ли рабочие веса, как часто получается тренироваться, как меняется вес тела.

Приложение делается для одного пользователя, поэтому оно работает полностью офлайн, без регистрации, серверов, рекламы и аналитики. Все данные хранятся на телефоне.

## 2. Задачи

| № | Задача | Как решается |
|---|--------|--------------|
| 1 | Записать тренировку в зале за минимум касаний | Экран активной тренировки: упражнения карточками, подходы строками, вес и повторения подставляются из прошлого подхода |
| 2 | Не держать программу в голове | Шаблоны тренировок (например, «Верх», «Низ», «Фулбоди»), старт тренировки из шаблона одной кнопкой |
| 3 | Соблюдать отдых между подходами | Таймер отдыха запускается автоматически после отметки подхода |
| 4 | Видеть прогресс | График расчётного 1ПМ и максимального веса по каждому упражнению, личные рекорды |
| 5 | Помнить, что делал в прошлый раз | История тренировок с детализацией по подходам |
| 6 | Следить за весом тела | Журнал веса с графиком |
| 7 | Не потерять данные | Системный Android Auto Backup (MVP), экспорт/импорт JSON (v0.2) |

## 3. Функционал по версиям

### v0.1 — MVP (реализовано в этой ветке)

- **Справочник упражнений**: ~40 базовых упражнений по группам мышц, поиск, добавление своих.
- **Активная тренировка**: пустая или из шаблона; добавление/удаление упражнений и подходов; ввод веса и повторений; отметка выполнения; секундомер длительности; завершение или отмена. Незавершённая тренировка переживает закрытие приложения.
- **Таймер отдыха**: стартует после отметки подхода (по умолчанию 90 с), кнопки ±15 с и «Пропустить».
- **Шаблоны**: создание, редактирование, удаление; старт тренировки из шаблона с заданным числом подходов.
- **История**: список завершённых тренировок (дата, длительность, число подходов, тоннаж), детальный просмотр, удаление.
- **Прогресс**: выбор упражнения, график расчётного 1ПМ (формула Эпли) по тренировкам, рекорды — максимальный вес, лучший 1ПМ, максимальный тоннаж за тренировку.
- **Вес тела**: добавление замеров, график, список с удалением.
- **Главная**: сводка недели (тренировок, подходов, тоннаж), продолжение незавершённой тренировки, быстрый старт.

### v0.2 — удобство и надёжность

- Экспорт/импорт всех данных в JSON через системный выбор файла.
- Настройки: длительность отдыха по умолчанию, вибрация/звук по окончании таймера, шаг веса.
- Уведомление с таймером отдыха при свёрнутом приложении.
- Подсказка «в прошлый раз» (вес × повторения) рядом с каждым подходом.
- Типы подходов: разминочный / рабочий / до отказа.

### v0.3 — развитие

- Кардио и упражнения на время (планка, бег): подходы «время/дистанция».
- Календарь тренировок (тепловая карта).
- Замеры тела (талия, грудь, бицепс), фото прогресса.
- Виджет на рабочий стол «Начать тренировку».
- Интеграция с Health Connect (запись тренировок и веса).

## 4. Экраны и навигация

Нижняя навигация из четырёх вкладок:

```
┌──────────────┬──────────────┬──────────────┬──────────────┐
│  Тренировка  │   История    │   Прогресс   │  Вес тела    │
└──────────────┴──────────────┴──────────────┴──────────────┘
```

| Экран | Содержание | Переходы |
|-------|-----------|----------|
| Тренировка (главная) | Карточка «Продолжить» при наличии незавершённой тренировки, сводка недели, кнопка «Пустая тренировка», список шаблонов с кнопкой «Начать», «Новый шаблон», «Упражнения» | → Активная тренировка, → Редактор шаблона, → Справочник |
| Активная тренировка | Верхняя панель с секундомером и кнопкой «Завершить»; карточки упражнений со строками подходов «№ · кг · повт · ✓»; «+ Подход»; «+ Упражнение»; «Отменить тренировку»; плашка таймера отдыха снизу | → Выбор упражнения |
| Выбор упражнения / Справочник | Поиск, список по группам мышц, «+ Своё упражнение» | ← возврат с выбранным упражнением |
| Редактор шаблона | Название, упражнения с числом подходов (−/+), удаление, «+ Упражнение», «Сохранить», «Удалить шаблон» | → Выбор упражнения |
| История | Карточки завершённых тренировок | → Детали тренировки |
| Детали тренировки | Дата, длительность, тоннаж, упражнения и подходы; удаление | ← История |
| Прогресс | Выпадающий выбор упражнения, график 1ПМ, рекорды | — |
| Вес тела | Поле ввода и «Добавить», график, список замеров | — |

## 5. Визуальная концепция

- **Material 3**, тёмная и светлая темы переключаются вслед за системной настройкой; основной сценарий — тёмная (в зале экран не слепит).
- **Акцентный цвет** — энергичный оранжевый `#FF6B35`, вторичный — бирюзовый `#2EC4B6` для графиков и отметок выполнения. Динамические цвета Android 12+ отключены, чтобы сохранить узнаваемый стиль.
- **Крупные зоны касания** (не меньше 48 dp) и крупные цифры в полях веса и повторений — вводить приходится потными руками между подходами.
- **Выполненный подход** подсвечивается фоном вторичного цвета — видно, сколько осталось.
- **Графики** рисуются собственным компонентом на Canvas: линия с точками, подписи минимума и максимума, без сторонних библиотек.
- **Иконка** — векторная гантель на оранжевом фоне (adaptive icon).

## 6. Архитектура

```
UI (Jetpack Compose, Material 3, Navigation Compose)
        │  StateFlow
ViewModel (по одному на экран)
        │
Repository (FitnessRepository — единая точка доступа к данным)
        │
Room (SQLite): DAO + Entity
```

- Язык — **Kotlin**, UI — **Jetpack Compose**, хранение — **Room**, асинхронность — **Coroutines/Flow**.
- Внедрение зависимостей — ручной контейнер `AppContainer` в `FitnessApp` (для одного модуля Hilt избыточен).
- `minSdk 26` (Android 8.0), `targetSdk 35`.
- Один Gradle-модуль `app`; версии зависимостей — в `gradle/libs.versions.toml`.

### Модель данных

| Таблица | Поля | Назначение |
|---------|------|-----------|
| `exercises` | id, name, muscleGroup, isCustom | Справочник упражнений |
| `workouts` | id, name, startedAt, finishedAt (null — идёт) | Тренировки |
| `workout_sets` | id, workoutId, exerciseId, exerciseOrder, setOrder, weight, reps, done | Подходы; порядок упражнений в тренировке задаётся `exerciseOrder` |
| `templates` | id, name | Шаблоны |
| `template_exercises` | id, templateId, exerciseId, position, sets | Состав шаблона |
| `body_weights` | id, date, weight | Замеры веса |

Удаление тренировки или шаблона каскадно удаляет подходы и состав. Упражнение, использованное в истории, удалить нельзя (ограничение внешнего ключа `RESTRICT`).

### Расчёты

- **Расчётный 1ПМ** (одноповторный максимум) по формуле Эпли: `вес × (1 + повторения / 30)`; для одного повторения — сам вес.
- **Тоннаж** — сумма `вес × повторения` по выполненным подходам.
- В статистику попадают только подходы, отмеченные выполненными.

## 7. Сборка, установка, выпуск

- Сборка — GitHub Actions (`.github/workflows/android.yml`) на каждый push: юнит-тесты, debug и release APK, артефакт `fitness-apk`.
- Тег `v*` (например, `v0.1.0`) дополнительно создаёт GitHub Release с APK.
- Debug-сборка ставится рядом с release (`applicationId` с суффиксом `.debug`).
- Подпись: debug-ключ лежит в репозитории, чтобы сборки обновлялись друг поверх друга. Для release можно завести собственный ключ через секреты репозитория (см. README), иначе release подписывается тем же debug-ключом.

## 8. Риски и ограничения

- Данные только на устройстве: до выхода экспорта (v0.2) сохранность обеспечивает только Android Auto Backup в Google-аккаунт.
- Смена ключа подписи потребует удалить приложение перед установкой новой сборки — с потерей данных, поэтому ключ лучше определить до начала реального использования.
- Поскольку debug-ключ в репозитории общедоступен при публичном репозитории, APK с таким ключом годится только для личного использования.
